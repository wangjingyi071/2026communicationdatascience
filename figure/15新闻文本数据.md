## 一、定义

**新闻文本数据**（News Text Data）是指以新闻报道为载体、以自然语言文字为主要表现形式的数字化文本集合，既包括新闻标题与正文，也涵盖发布时间、来源机构、作者、阅读量等元数据。它是计算传播学研究中最常用的**非结构化数据**类型之一。

简单来说，报纸网站上的一篇报道、通讯社的一条快讯、媒体官微发布的一条新闻帖，都属于新闻文本数据。

## 二、背景与应用场景

随着传统媒体数字化转型与新媒体平台兴起，新闻内容从纸质走向网络，每日产生海量可被机器读取的文本数据。**计算传播学**借助自然语言处理（NLP）与数据挖掘技术，将这些文本转化为可量化分析的对象，从而突破传统内容分析法样本量小、主观性强的局限。

在传播学、计算传播领域，新闻文本数据的典型应用场景包括：

- **议题设置研究**：通过统计关键词或主题的出现频次，检验媒体议程的形成与演变，呼应麦库姆斯与肖的议题设置理论。
- **框架分析**：识别媒体对同一事件的报道框架（如责任归因、冲突、人情味），揭示不同媒体的立场差异。
- **舆情监测与预警**：基于情感分析与主题建模，实时追踪社会情绪波动，为舆情研判提供数据支撑。
- **传播网络分析**：结合新闻文本的引用与转载关系，构建信息传播网络，分析跨媒体议程扩散路径。
- **议程融合研究**：将新闻文本与社交媒体文本结合，考察传统媒体议程与公众议程之间的互动关系。

## 三、数据特点

- **时效性强**：新闻文本随事件动态产生，具有明确时间戳，能反映特定时间窗口内的社会关注焦点。
- **结构化与非结构化并存**：标题、时间、来源等字段结构化，正文属于自由文本，需 NLP 技术解析。
- **规模庞大**：每日全球产生海量报道，累积形成超大规模语料库。
- **语言相对规范**：相较于社交媒体口语化文本，新闻用词正式、语法规范，便于机器处理。
- **主题覆盖广泛**：涵盖政治、经济、社会、科技、文化等领域，适合跨议题比较研究。
- **元数据丰富**：附带机构、时间、栏目、阅读量等信息，支撑多维度分析。

## 四、数据获取与处理

1. **数据采集**：通过网络爬虫（如 Python 的 Scrapy、BeautifulSoup）或平台 API 批量获取新闻页面，解析提取标题、正文、时间、来源等字段，存储为 CSV 或 JSON。

2. **数据清洗**：去除广告、导航栏、重复转载等噪声；统一日期格式；处理缺失值与乱码。

3. **文本预处理**：中文文本进行**分词**（如 jieba、HanLP）、去停用词、词性标注；英文文本进行词形还原（Lemmatization）与词干提取（Stemming）。

4. **特征工程**：将文本转化为数值特征，常用词袋模型（Bag-of-Words）与 TF-IDF 权重。TF-IDF 公式为：

$$
tfidf(t, d) = tf(t, d) \times idf(t)
$$

其中逆文档频率 $idf(t) = \log \frac{N}{df(t)}$，$N$ 为文档总数，$df(t)$ 为含词语 $t$ 的文档数，用于降低高频常见词权重、突出区分度关键词。

5. **文本分析与可视化**：选用主题建模（LDA）、情感分析、词向量（Word2Vec、BERT）等方法，并用词云、时序图、网络关系图呈现结果。

| 阶段 | 主要任务 | 常用工具 |
|------|----------|----------|
| 采集 | 抓取新闻页面 | Scrapy、BeautifulSoup |
| 清洗 | 去重、去噪、补全 | Pandas、正则表达式 |
| 预处理 | 分词、去停用词 | jieba、HanLP |
| 特征工程 | 向量化、TF-IDF | scikit-learn |
| 分析建模 | 主题、情感、分类 | Gensim、BERT |

## 五、优缺点

### 优点

- **覆盖面广**：能集中反映特定时期社会各领域的重要事件与公共议题。
- **可追溯性强**：具备明确时间戳与来源标识，便于历时性比较研究。
- **文本质量较高**：语言规范、信息密度大，噪声相对较少。
- **获取成本较低**：大量文本可通过网页抓取或公开 API 获取，历史数据易回溯。

### 缺点

- **代表性偏差**：新闻文本反映的是媒体机构的选择与框架，不能直接等同于公众真实意见。
- **版权与合规限制**：部分数据受版权保护，抓取需遵守网站 robots 协议。
- **数据噪声**：网页抓取常混入广告、重复转载等冗余内容，需额外清洗。
- **标注成本高**：监督学习任务中高质量人工标注（情感、立场、框架）耗时且昂贵。
